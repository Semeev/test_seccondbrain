# YouTube Horror Channel — США аудитория

> Идея зафиксирована 16.03.2026. Статус: идея, не проработана.

---

## Суть

Создать YouTube-канал с хоррор-контентом для американской аудитории.
Монетизация через AdSense (CPM у США-аудитории в 5–15x выше СНГ).

---

## Почему США и Horror

| Критерий | Почему это работает |
|---|---|
| CPM США | $5–20 vs $0.5–2 для СНГ |
| Horror на YouTube | Миллиарды просмотров, стабильный спрос |
| Нет языкового барьера | Можно делать без речи: нарезки, атмосфера, subtitles |
| Алгоритм | Horror хорошо вирусится — клики по превью высокие |

---

## Форматы контента

| Формат | Сложность | Примеры |
|---|---|---|
| Compilations / Top lists | Низкая | "Top 10 Scary Moments Caught on Camera" |
| Creepypasta narration | Средняя | Озвучка страшных историй |
| Reddit horror stories | Низкая | Текст + AI-голос + атмосферное видео |
| Found footage | Средняя | Монтаж "настоящих" записей |
| Horror game highlights | Низкая | Нарезки из игр (правовой вопрос) |

---

## Монетизация (после 1000 подписчиков / 4000 часов)

| Источник | Потенциал/мес |
|---|---|
| AdSense (100k views, CPM $8) | ~$800 |
| Спонсорство (VPN, horror apps) | $200–500 |
| Мерч / Patreon | $100–300 |
| **Итого при 100k views** | **$1000–1600** |

---

## Риски

- Copyright Strike при использовании чужого footage
- Долгий старт: монетизация открывается после 1000 подписчиков
- YouTube может деплатформировать gore-контент (нужны правила)
- Конкуренция высокая — нужна своя "фишка"
