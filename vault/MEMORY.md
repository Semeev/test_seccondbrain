- Телефоны поставщиков (контакты, контактные лица) — РАЗРЕШЕНО показывать в приложении, это его рабочая база (решение 26.11.2026: «что за база поставщиков без номеров»). Номер, присланный пользователем, помечать «актуальный».
- Пользователь любит: короткие ответы, всё сохранять (файлы → исходники/входящие + GitHub, каждую правку приложения — коммит), не путать оплаты с задачами, называть поставщиков по юрлицу, если просит
