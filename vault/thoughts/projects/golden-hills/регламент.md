# Голден Хилс — регламент мониторинга цен

- `Мониторинг_цен_Ташкент.xlsx` — рабочий файл: «Сводка», «Журнал цен», «Поставщики», «Позиции», «Инструкция».
- `сводки/Сводка_цен_ГГГГ-ММ-ДД.pdf` — ежедневные PDF-сводки.
- `данные/цены_ГГГГ-ММ-ДД.json` — что собрано за день (для истории), `данные/выводы_ГГГГ-ММ-ДД.txt` — выводы дня.
- `исходники/` — файлы пользователя как прислал (поставщики, запрошенные цены / КП).
- `tools/` — скрипты: `wbtools.py` (добавление позиций/поставщиков без пересоздания файла), `import_2026_11_23.py` (разовый импорт файлов пользователя), `add_prices.py` (дописать цены в журнал), `digest.py` (PDF), `build_workbook.py` (создание файла с нуля — **не запускать** поверх рабочего файла, затрёт ручные данные).

## Поставщики пользователя и КП

- В листе «Поставщики»: «Работаем = Да» — поставщики пользователя (контакты, контактное лицо). В сводке колонки «Мин. у наших поставщиков» и «Наша цена к рынку».
- **Повторная присылка тех же файлов (КП или поставщики, имена могут быть искажены):**
  ```
  python tools/sync_user_files.py <файл(ы)>            # пробный прогон: что новое/изменилось, что не сопоставлено
  python tools/sync_user_files.py <файл(ы)> --apply    # записать; затем recalc.py и digest.py
  ```
  Тип файла определяется по шапкам. Сравнение — со снимком прошлой версии (`данные/снимок_*.json`): добавляются только новые строки и изменившиеся цены (в комментарии «было …»). Несопоставленные поставщики/позиции («❓») — дописать в `данные/сопоставление.json` (при необходимости добавить позицию через `wbtools.add_positions`) и запустить снова; если смысл неясен — спросить пользователя.
- Новый файл/вкладка с КП от пользователя: сравнить с `исходники/`, перенести только новое в `данные/кп_ДАТА.json` (source = «КП (письменное)», дата КП, кол-во в комментарии), новые позиции и поставщиков — через `wbtools.add_positions` / `wbtools.upsert_supplier`, затем `add_prices.py`. Неясные места (нет единицы, опечатки в классе/диаметре) — не угадывать, а спросить пользователя. Сохранить присланный файл в `исходники/`.

## Прямые источники: заводы и склады, без перекупов (главный приоритет)

Цель — цены производителей, их складов и официальных дистрибьюторов. Тип в листе «Поставщики» ставим только с **основанием** (колонка L):
- **Завод-производитель** — на сайте/в карточке есть адрес производства, фото цеха/линий, сертификаты производства, «являемся производителем», официальный прайс завода; либо это биржа UZEX (торги заводов).
- **Склад/дистрибьютор** — собственные склады с адресами и запасом (т, м³), «продажа со склада», статус официального дилера завода (подтверждён на сайте завода).
- **Перекупщик** — признаки: только офис/бизнес-центр без склада, «привезём с любого завода», ассортимент «всё подряд» из разных категорий, цена бренда выше официального прайса завода, нет адреса склада, телефон-однодневка.
- **Магазин (розница)** — строительные/электро-магазины, маркеты.
- Нет данных — «Не проверено» (в блок «Заводы и склады» не попадает).

Сводка — по **всему рынку** (заводы, склады, дистрибьюторы, трейдеры, магазины, объявления, КП): мин./средняя/макс. по всем, плюс разбивка «заводы/склады» vs «магазины/трейдеры» и наценка посредников. Магазины и трейдеры собираем наравне с заводами.

Ежедневно в первую очередь: сайты заводов/складов из реестра (тип Завод/Склад, колонка «Сайт»), затем поиск новых производителей по каждой категории (заводы бетона/РБУ, металлобазы со складами, цементные заводы, заводы газоблока, трубные и кабельные заводы, официальные дилеры). Источник в журнале — «Сайт завода/склада». Агрегаторы и объявления — только для полноты статистики.

Сетевой доступ: сайты открываются, только если хост есть в списке разрешённых в среде «test_seccondbrain — мониторинг цен». Новый сайт не открылся (403/ENOTFOUND) — записать хост в отчёт; добавляем пачкой с подтверждением пользователя (update_environment).

В сводке Excel (колонки G–H, T–V) и PDF (зелёный блок) — мин./средняя/макс. отдельно по заводам и складам, рядом со статистикой по всем источникам.

## Ежедневный сбор (регламент)

1. Синхронизировать ветку `claude/sharp-mendel-txik2r` (`git fetch` + merge), работать в `vault/thoughts/projects/golden-hills/`.
2. Собрать текущие цены, в порядке приоритета:
   1. **Сайты наших поставщиков** — лист «Поставщики», строки с «Работаем = Да» и заполненным сайтом. Ищем сайт, если его нет, и записываем в колонку сайта.
   2. **UZEX** (uzex.uz) — итоги торгов / дайджесты по цементу и металлу.
   3. **stroyka.uz** — карточки с ценой за м³ / т / м² и датой обновления.
   4. **prom.uz, glotr.uz, olx.uz** — объявления.
   5. Новые источники с датированными ценами — проверить и добавить в этот список.
3. Правила записи:
   - Только цены, у которых понятна единица; пересчёт за лист/штуку/мешок — через коэффициент (`coef`).
   - Карточки с датой обновления старше 6 месяцев — не записывать (или с пометкой в комментарии, если других цен нет).
   - Явные опечатки (цена в 10 раз ниже рынка) — не записывать.
   - В комментарии — дата обновления карточки, НДС/доставка, если указаны.
   - Позиция — строго название из листа «Позиции». Если нужной нет — сообщить пользователю, а не придумывать.
   - Источник: «Сайт» (сайт поставщика / агрегатор), «Объявление», «Биржа UZEX».
4. Сохранить собранное в `данные/цены_ДАТА.json` и запустить:
   ```
   python tools/add_prices.py Мониторинг_цен_Ташкент.xlsx данные/цены_ДАТА.json
   python <xlsx-skill>/scripts/recalc.py Мониторинг_цен_Ташкент.xlsx 300
   python tools/digest.py Мониторинг_цен_Ташкент.xlsx сводки/Сводка_цен_ДАТА.pdf --date ДАТА --notes данные/выводы_ДАТА.txt
   ```
   `выводы_ДАТА.txt` — 3–6 коротких выводов дня (что подорожало, где дешевле всего, что подозрительно).
5. Закоммитить и запушить, коротко отчитаться: сколько цен, главные изменения, что требует внимания.
