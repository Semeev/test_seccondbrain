## Как генерировать новый счёт
1. Взять предыдущий счёт нужного покупателя как шаблон (ИП Вероника)
2. Заменить: номер счёта, дату, сумму цифрами и прописью
3. Инструмент: PyMuPDF через Claude Code
4. Сохранить как новый файл, оригинал не трогать
