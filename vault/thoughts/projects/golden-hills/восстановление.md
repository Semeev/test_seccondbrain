# Если всё слетит — как восстановить

## Какое это приложение
- **Название:** «Снабжение Golden Hills»
- **Как называет пользователь:** «300 снабженцев» (так подписан значок на телефоне и на ПК; значок — `icon/300-snabzhencev.ico`, `icon/apple-touch-icon-180.png`)
- **Ссылка:** https://claude.ai/artifact/ULPEFRmFtMLX8oHpDWP9r4 (id артефакта `dd5b92ff-0d8d-41cb-b62e-037c1eaad3bd`)
- **Вкладки:** Категории · Поставщики · Сводка · Задачи · Оплаты
- **Права (capabilities):** `{"db":{"rules":[{"path":"payments","read":"view","write":"owner"}]},"user":{},"downloads":true}` — счета правит только владелец, остальные смотрят по ссылке без входа (снимок `payments.json`)
- Если пользователь говорит «300 снабженцев», «приложение снабжения», «приложение Golden Hills» — это оно.


Всё, что есть в работе по Golden Hills, хранится в GitHub: репозиторий `semeev/test_seccondbrain`, ветка `claude/sharp-mendel-txik2r`, папка `vault/thoughts/projects/golden-hills/`. История изменений (коммиты) позволяет вернуть любое прошлое состояние.

| Что | Где копия | Как часто обновляется |
|---|---|---|
| Журнал цен, поставщики, позиции | `Мониторинг_цен_Ташкент.xlsx` | при каждом сборе цен и импорте КП |
| PDF-сводки | `сводки/` | каждый день |
| Договоры, КП, счета (оригиналы) | `исходники/` | при получении |
| Код приложения | `app/index.html` (+ `tools/build_app.sh`) | при каждой правке |
| Задачи и «Оплаты» из приложения | `данные/резервная_копия_приложения.json` | каждое утро + при каждом обновлении приложения |
| Реестр источников, регламент | `данные/источники.json`, `источники.md`, `регламент.md` | при изменениях |
| Дневник и решения | `vault/daily/`, `vault/MEMORY.md` | каждый день |

Кроме того, сама страница приложения на claude.ai хранит историю версий — прошлую версию можно вернуть оттуда.

## Как восстановить
- **Приложение сломалось или пропало** — попросить Claude: «восстанови приложение из GitHub». Он соберёт его заново (`tools/build_app.sh`) и опубликует по той же ссылке (или по новой, если старой нет).
- **Пропали задачи или оплаты в приложении** — «восстанови задачи и оплаты из резервной копии»: Claude запишет документы из `данные/резервная_копия_приложения.json` обратно в базу приложения. Потеряется максимум то, что было отмечено после последней копии (не больше суток).
- **Испортился журнал Excel** — «верни журнал на вчерашнюю версию»: Claude возьмёт файл из истории GitHub.
